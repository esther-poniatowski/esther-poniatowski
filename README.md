# Esther Poniatowski

`@esther-poniatowski`

PhD candidate in Cognitive Neuroscience at the École Normale Supérieure (ENS), Paris. My research focuses on understanding how neuronal networks encode and process information, particularly in context-dependent tasks. It combines theoretical modeling with the analysis of empirical data to investigate the computational mechanisms underlying flexible behavior.

## Research and Technical Focus

- **Research Interests**: Neuronal Networks, Deep Networks, Recurrent Networks, Representational Geometry, Information Processing, Distributed Coding, Computational Cognitive Science, Theoretical Modeling
- **Programming Languages**: Python
- **Machine Learning Frameworks**: PyTorch, scikit-learn

### Research

**[Neural Computation Research](https://github.com/stars/esther-poniatowski/lists/neural-computation-research)**: Research on representation, encoding and learning in artificial and biological neural networks, via theoretical modeling and data analysis.

- [multitask-context-dependent-behavior](https://github.com/esther-poniatowski/multitask-context-dependent-behavior): Analysis of neuronal recordings from naive and trained animals performing multiple tasks in active and passive attentional states.
- [network-learning-structured-tasks](https://github.com/esther-poniatowski/network-learning-structured-tasks): Simulation framework for studying network learning on structured tasks, from task generation to representation analysis.
- [ubc-synapse](https://github.com/esther-poniatowski/ubc-synapse): Modeling of signal filtering in the synapse between Mossy Fibers and Unipolar Brush Cells.
- [Massi2022](https://github.com/esther-poniatowski/Massi2022): Comparison of reinforcement learning strategies inspired by hippocampal replay for robotic navigation.
